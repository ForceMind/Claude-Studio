WINDOWS 桌面浏览器

两个账户，
一个窗口。

在同一个浏览器里切换账户 A 和 B。各自保留登录和标签，代理状态、出口 IP、网页语言和时区集中显示。

下载 Windows 安装版 v0.8.1 下载 Windows 便携版 v0.8.1 试试账户切换

主要功能

登录与标签各自保留

A、B 使用各自的 Chromium 会话，分别保存网站数据、标签和选中页。

同一处查看账户环境

在右侧环境卡切换账户，查看代理连通状态、网页语言和时区，按需检测出口。

Claude、邮箱和认证

从窗口直接打开 Claude 和已设置的邮箱，认证弹窗沿用打开它的账户会话。
